# Benson Fireplace Manual Model Quick Reference Index

Status: Starter index for Sales Agent / department reference
Created for: Benson Stone Fireplace Sales Agent v2
Purpose: Help Drew and the Sales Agent quickly recognize model names, manual families, likely product category, and where to look next without treating old manuals as current sales truth.

## IMPORTANT USE RULE

Manuals are lookup references, not automatic sales recommendations. This index is meant to help identify likely model families and locate the right source document. It should not be used by itself to promise current availability, current pricing, current code compliance, exact part compatibility, exact venting compatibility, final clearances, or installation feasibility.

When using this index, always separate:
1. Model recognition: "This appears to be a likely manual/reference for that model."
2. Sales guidance: "Here are the questions to ask and likely product family."
3. Verification: "Confirm with current manufacturer manual, current price book, Liam/Rick, Phil/Rodney, or manufacturer rep before quoting or committing."

## Escalation

- Product/model uncertainty: Liam -> Rick -> manufacturer rep.
- Install feasibility, venting, clearances: Phil's install team or Rodney.
- Code, permit, county/local questions: Liam.
- B-vent questions: Liam.

## Manual Lookup Workflow for the Sales Agent

When a customer gives a model name, brand, manual photo, tag, or old unit name, the agent should respond with this structure:

1. **Likely match** "This sounds like it may match [brand/model/file], but I would verify the tag/manual before treating it as exact."

2. **Ask for identifiers**
   - Brand
   - Model number
   - Serial number only if needed for internal/service use; do not expose broadly
   - Fuel type
   - Fireplace/stove/insert/log set
   - Photos of unit, tag, firebox, surrounding wall, vent/chimney/termination

3. **Explain safe next step**
   - For sales path: identify possible replacement/upgrade direction without promising fit.
   - For service/parts: check parts manual/current manufacturer source.
   - For install/venting: route to Phil/Rodney or Liam.
   - For price/availability: use current price book or vendor portal.

4. **Customer-safe wording** "Based on the model name, I have a reference manual we can check, but I do not want to guess from the name alone. If you can send a photo of the model tag and the fireplace area, we can verify what you have and what options make sense."
