# Board 05 — Take-Home Summary

## Purpose
Define what the customer carries away — on the Summary screen, in email, in PDF, or as a printed sheet. This is the artifact that lives on their kitchen counter for a week. It must feel like a keepsake, not a receipt. This board sets the visual language for that final moment.

## What images to include
- Premium printed brochures / lookbooks (architecture, watch, furniture, hotel)
- Editorial product summary pages — final spec sheets that feel beautiful, not technical
- Wedding/hospitality stationery — the way it handles names, places, and a single hero image
- Email confirmations from premium brands (Aesop, Aman, Bulthaup, RH) — restrained, typographic
- Printed "build sheets" from premium auto deliveries — the page they slip in the glovebox
- Personal letterpress / single-page keepsakes — invitations, menus, programs
- PDF examples saved as images — page layouts only, no interactive UI

## What Claude Design should learn
- A summary is a portrait, not a list — one hero image, then quiet annotation
- Typography does the heavy lifting; color does almost nothing
- The customer's selections are named generously ("Cliffstone, with a rustic oak mantel and bluestone hearth") — not as fields with labels
- Margins are wide, line lengths are short, and the page is meant to be held
- One subtle mark of provenance (Benson Stone, date, session reference) — never a watermark or barcode
- The artifact must work printed on plain office paper and still feel intentional

## What Claude Design should avoid
- "Your order summary" / "Order #12345" e-commerce framing
- Tables, line items, SKU columns, quantity fields
- Any pricing, dealer cost, supplier, internal reference numbers (see `CUSTOMER_SAFE_BOUNDARY.md`)
- Marketing footers — social icons, "follow us," promotional banners
- QR codes for marketing (acceptable only if functional — e.g., resume session)
- "Generated by AI" / "Powered by" tags
- Glossy stock-photo couples next to the summary
- Anything that looks like an invoice, quote, estimate, or proposal

## Suggested file naming convention
```
05-summary__<format>__<source>__<id>.<ext>
```
Formats: `print`, `email`, `pdf`, `stationery`, `web`
Examples:
- `05-summary__print__porsche-delivery-card__001.jpg`
- `05-summary__email__aman-confirmation__002.png`
- `05-summary__pdf__bulthaup-brochure-page__003.jpg`
- `05-summary__stationery__letterpress-menu__001.jpg`
- `05-summary__web__nomos-summary-screen__001.png`

## Notes for Drew while gathering images
- Photograph physical brochures and cards from above, flat, in natural light — don't scan if you can help it; you lose the paper.
- Note paper weight / finish if you know it. Uncoated cover stock reads completely different from glossy.
- For digital references, grab the full email or page, not just a crop. The whole rhythm matters.
- If a piece feels too cold or corporate, skip it — we want warmth without sentimentality.
- Keep at least three references that work on plain 8.5x11 white paper. We will be printing in store.
- The "kitchen counter test": if you can imagine this sitting on a kitchen counter for a week and still feeling good on day seven, save it. If not, don't.
