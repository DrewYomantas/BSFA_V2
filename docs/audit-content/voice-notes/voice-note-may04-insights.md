## 5. Product specs / anatomy

### Napoleon Prestige Pro 665 Elite NG (grill)
- **NG = Natural Gas** (variant suffix on part number)
- Comes standard with **rotisserie kit** — so a customer note asking for a rotisserie is redundant (verify via the price book before adding as a line item)
- **Item-add procedure in BisTrack** when not in system:
  - Item code prefix: **FP-** (Drew confirms "Fp. When we're adding an item into our system")
  - Description format: **`[Brand] [Model] [Variant] - [Part Number]`** → e.g. `Napoleon Prestige Pro 665 Elite NG-[partnum]`
  - Always include the **part number after a dash** at the end

### Wood-stove vent stack-up (Haas Q&A — canonical reference)
- **First floor (visible from stove):** **black pipe** straight up to the ceiling
- **Transition at first ceiling:** **support box** — supports pipe weight, acts as **fire stop**, insulated
- **Second floor (interior, inside wall/floor):** **galvanized insulated Class A pipe** ("looks the same as stainless but cheaper")
- **At the floor of the second floor:** a **collar / collar trim** wraps around the pipe
- **Through the attic:** **attic insulation shield** keeps insulation away from the pipe (install BEFORE blowing insulation if possible)
- **Above the roof line (exterior, exposed):** **stainless steel Class A chimney** (must be stainless when exposed to weather)
- **Insulation spec:** Class A pipe = **1 inch of insulation all the way around** ("double insulated")
- **Clearance rule:** As long as you hit the **minimum clearance from the back of the stove to the wall**, you do **NOT need a non-combustible backing**. (No fireproof board required when clearance is satisfied.)
- **Galvanized vs stainless cost note:** Galvanized is the cheaper Class A option for interior; "you don't need to do stainless, but it looks the same."
- **Paintability:** Galvanized **is not made to take paint** — can be sanded with aggressive grit + painted, but rarely done and won't look perfect.

### Masonry-fireplace anatomy (Chelsea walk-in)
- Walk-in's fireplace is a true **masonry fireplace** = built up out of **cinder block** behind the brick veneer (installer: "majority of them I've seen, if not all, are cinder block storm encasement")
- The **brick face** can be cleaned with a **special cleaner** + scrub but result is never pristine
- **Mantle / hearth top stone replacement:** **Limestone** is Drew's go-to substitute for missing/damaged top stones
- **Carpet/wood-trim removal path:** Pull carpet/wood → expose cinder block → **screw drywall into the cinder** → mud/tape/paint OR **re-stone** the whole face
- **Slate (top piece on existing fireplace):** "machined oil-on" slate ledge stone — typical for 1940s-era builds

4. **Always go with the HIGHER number on a delivery-price discrepancy.** ($125 in Jonathan's notes vs. $150 verbal → use $150.)
5. **Confirm scope on the phone BEFORE writing the order** — Drew called Miller specifically because Jonathan's desk had conflicting notes (a full accessories list vs. an updated note saying "just the grill"). Don't trust stale paper notes.
6. **Paste addresses through Google first** to catch ASR / handwriting errors before they hit BisTrack. (Miller's note had a partial address + a GPS coordinate.)
7. **"INST / SVC / DLV"** — three-letter customer-reference code so warehouse + delivery team can sort quickly.
8. **Hold floor models on a last-name only.** Liam's hold call needed nothing more than "your last name" to put the T4LE on reserve.
9. **Sell V1 floor models at a discount when V2 launches.** Liam: "Happy to sell that at a better price" — standard playbook for clearing display units when a new generation arrives.
10. **Gate Rodney's site visits behind scope.** Don't dispatch project manager until the customer has a rough direction. Saves Rodney's day.

## 13. Coaching takeaways (for Drew's training docs)

1. **The "cover for free" move** — when a customer asks for a discount on an MSRP-locked vendor product, **substitute a free accessory** instead of touching the headline price. Preserves vendor relationship + rep margin.
2. **Phone-confirm scope before writing an absent rep's order** — never trust the paper notes alone, especially if multiple notes contradict.
3. **CC the absent rep on every email** so they're current when they return.
4. **Higher delivery quote wins** when verbal and written numbers conflict.
5. **Hold-call script** — take last name only, lock the unit, leave a desk note. Don't make customers re-justify a hold.
6. **Gate the project manager visit** behind a customer who has at least a rough direction — saves Rodney's day and produces better advice when he does go.
7. **Wood-stove pipe stack-up Q&A is high-frequency** — Liam was asked about every junction (1st-floor → 2nd-floor → roof). Memorize the four-segment stack (black → galvanized → galvanized through attic → stainless above roof) + the support box / collar / fire stop / attic insulation shield names.
8. **"Blank canvas" reframe** — when a walk-in is vague about scope, name it explicitly: "You're a blank canvas. It depends on what you want to spend." Gives the customer permission to think out loud.
9. **MSRP discipline applies even when you're filling in** — protecting the absent rep's margin builds team trust and is a competitive advantage Drew wants Liam to internalize.
